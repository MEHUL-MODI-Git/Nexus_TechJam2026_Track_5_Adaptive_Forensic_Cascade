05 The fair comparison

We handicapped ourselves, and still report the smaller number.

Any detector catches more fakes by accusing more images. The baseline accuses a real photo 0.27% of the time; we accuse 8.3%. That is a difference in setting, not skill — so we removed our advantage: we set the baseline to accuse at exactly our rate, and let it tune on the test set itself, which we never did.

33%
baseline, tuned in its own favour
→
83%

+49.2 points, CI95 [+47.5, +50.8], paired source bootstrap. That is the number we publish.
